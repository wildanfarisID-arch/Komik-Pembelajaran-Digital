Panduan aktivasi Firebase & Security Rules
  1. Buka proyek komik-pembelajaran-digital di Firebase Console. Buat Firestore Database (default) dan aktifkan Storage. Cloud Storage memerlukan paket Blaze.
  2. Aktifkan Authentication → Sign-in method → Email/Password. Di Authentication → Users, pastikan akun login beserta kata sandinya sudah dibuat.
  3. Dokumen users/wildan@test.com boleh tetap disimpan, tetapi tidak diperiksa untuk login. Membuat dokumen Firestore tidak otomatis membuat akun Authentication.
  4. Salin Firestore Rules dan Storage Rules terbaru di bawah ke tab Rules masing-masing layanan, lalu Publish. Mengganti index.html tidak memperbarui Rules di server secara otomatis. Jika proyek memiliki aturan lain, gabungkan aturan untuk materials dan comics dengan aturan yang sudah ada.
  5. Tambahkan domain GitHub Pages Anda (misalnya nama.github.io) pada Authentication → Settings → Authorized domains. Untuk pengujian lokal, tambahkan localhost jika diperlukan.
  6. Login guru, unggah PDF, isi soal dan simpan. Siswa membuka situs yang sama, memilih materi, membaca PDF, lalu memulai kuis.

Materi dan soal dapat dibaca publik. Kunci jawaban dikirim ke browser untuk latihan, bukan untuk ujian dengan kunci rahasia. Skor kuis belum disimpan ke database.

Mode akses longgar: semua akun yang berhasil login dapat membuat materi. Pengunjung tanpa login hanya dapat membaca. Rules ini tidak membutuhkan koleksi users atau teachers.
